This project involves the analysis and prediction of IMDb movie ratings using data collected via web scraping. The primary objective is to explore how various features—such as genre, release year, vote count, and movie runtime—affect the IMDb rating of a movie. The workflow includes data cleaning and preprocessing (e.g., converting runtime formats), exploratory data visualization (e.g., boxplots and scatterplots), and the application of statistical and machine learning models such as linear regression to predict ratings.

Key components of the project include:

Data preprocessing to convert text-based runtime into numeric values (in minutes).

Exploratory Data Analysis (EDA) to visualize the relationship between genres, runtime, and ratings.

Statistical modeling using statsmodels to understand correlations and significance levels.

Predictive modeling using scikit-learn's LinearRegression to estimate IMDb ratings based on features like runtime and release year.

This analysis provides insights into what characteristics may contribute to higher movie ratings and demonstrates how simple linear models can be used for predictive analytics in a film-based dataset.
